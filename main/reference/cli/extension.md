# icp extension

Install and manage extensions: third-party commands run in a sandbox

**Usage:** `icp extension <COMMAND>`

###### **Subcommands:**

* [`install`](extension-install.md) — Install an extension as a command of icp, or replace an installed one
* [`list`](extension-list.md) — List installed extensions, one per line: name, version and source
* [`show`](extension-show.md) — Show an installed extension: where it came from, its sha256 and version, the canisters it may call, and its commands
* [`uninstall`](extension-uninstall.md) — Uninstall an extension
